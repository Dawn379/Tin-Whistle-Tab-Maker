## ✨ 功能特性
### 【重要】：
- 全按作2中，低音b2 b3 b4 b5 b6 b7指的是缓吹时由低到高发出的音，中音1 ~ 7和高音#1 #2 #3指的是急吹时由低到高发出的音
- 全按作5中，低音b5 b6 b7和中音1 ~ 3指的是缓吹时由低到高发出的音，中音4 ~ 7和高音#1 #2 #3 #4 #5 #6指的是急吹时由低到高发出的音
- 这个规则是本人秉持着“能用就行”的原则设计的，完全没有乐理可言，哈哈

| 功能 | 说明 |
|------|------|
| 双指法模式 | **全按作 5** / **全按作 2** 自由切换 |
| 低音 | b5 b6 b7（全按作 5）<br>b2 b3 b4 b5 b6 b7（全按作 2） |
| 中音 | 1 ~ 7（Do Re Mi Fa Sol La Si） |
| 高音 | #1 #2 #3 #4 #5 #6（全按作 5）<br>#1 #2 #3（全按作 2） |
| 休止符 | **0** 表示休止 |
| 延音/附点 | **-** 和 **.** 会自动跳过，不占谱位 |
| 小节线 | **\|** 竖线分隔不同小节，排版更整齐 |
| 图片导出 | 一键导出高清 PNG，自动带上谱名、指法、制谱信息 |

## 📖 使用教程

### 输入简谱

在左侧输入框粘贴或输入简谱，格式规则：

```
节拍与节拍之间用空格隔开  |  如果2个八分音符为一拍，则把两个音符连起来输入，如23，b2b3，#2#3等，以此类推  |  小节之间用竖线分隔  |  当然每个小节内输入什么随你心情，不符合音乐规则也不会怎么样，小节之间的竖线不要忘记就可以
例如：1 2 3. 4 | #1 12 3 0 | b5 6 7 1 | 5-- 5-- 5 6
```
- v5版本中，每满14个音符就会自动换行（如果没有换行的话，检查一下是不是因为忘了添加小节之间的竖线）（另外这个规则应该还同时配合着其他规则，但目前我也不太清楚其他规则是什么，总之结果就是，有的时候每行音符并不是精准的14个，但是问题不大）
- v6版本中，换行功能通过用户主动输入“回车键”实现。即如果用户希望自主控制什么时候换行，推荐用v6版本，当你想换行的时候，按下回车键即可。

### 导出 PNG

1. 在标题栏输入 **谱子名字**（必填）
2. 输入简谱 → 右侧实时预览洞洞谱
3. 点击 **「导出 PNG」** 按钮
4. 下载的图片包含：谱名标题、谱子主体、制谱署名、底部寄语
